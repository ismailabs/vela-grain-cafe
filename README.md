# Vela & Grain — Fictional Café Portfolio Project

A premium, responsive, animated restaurant portfolio website built with React, Vite, TypeScript, Tailwind CSS, and Motion for React.

> Vela & Grain is fictional. The business, menu, location, contact details, and reservation flow are created solely for portfolio demonstration.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion for React
- React Router

## Pages

- Home
- Menu
- About
- Gallery
- Contact

## Notes

- Photography is loaded from remote Unsplash HTTPS URLs.
- The footer uses the supplied `public/built-by-ismail.png` asset.
- Contact and reservation forms are client-side portfolio interactions only; they do not submit to a real business backend.
- Motion respects reduced-motion preferences.
